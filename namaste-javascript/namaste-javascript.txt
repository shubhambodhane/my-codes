JavaScript:

- JavaScript is single-threaded, Synchronous language.

- Everything happens inside Execution context. (combination of memory and code component)

- Memory component = Variable Environment = key value pair of variable and function:
like a=10, function = {}
- code component = Thread of execution = one command execution (one by one)

-> undefined = special keyword
- when function execution starts the memory gets assigned to variable, initially the variables gets initializes with "undefined". then the actual value get assigned to it when the function is called. (variable and function gets initializes)
- Execution context created for it code component, it starts execution one by one line

-> Call Stack:
- to manage the execution of the tasks it will be useful.
- the function gets executed in call stack. 
- Call Stack Follows LIFO. (Last in First Out) : chapati box
- call stack known by other names:
1. Program stack
2. control stack
3. Runtime stack
4. Machine stack

shadowing:
