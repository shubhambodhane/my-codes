Hoisting in JavaScript:

- It is the default behavior of moving variables declaration to top before the execution of the function.
- variables: var, let, const follow hoisting
- the arrow function will also supports hoisting as it will acts as variable.
ex. const myFun = ()=> { // my code}; // myFun will behave like variable

- In the execution context, the memory first allocated to variables
the variables gets initializes with undefined.
- when the function gets called then the actual value gets assigned to it.

-> Undefined vs not defined (null):
- the variable is declared without the value. ex let a;
- the variable is declared with intention as null. ex. let b = null; 

-> Temporal dead zone:
- Time it takes to get actual value assigned to the variable. this is Temporal dead zone.
//------------------------------------------------------------------------------
ex.
function myFun(){
console.log(a);
var a = 10;
}
myFun();

//output:
//undefined
//------------------------------------------------------------------------------
ex.
function myFun(){
console.log(a);
let a = 10;
}
myFun();

//output:
//error reference error: temporal dead zone
//------------------------------------------------------------------------------
ex. arrow function acts as a variable

console.log(a);
const a =()=>{return "hello" };
